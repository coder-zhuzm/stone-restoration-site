本文档最初用于规划图片生成、局部编辑、素材清理和模型选型；以下是当时的记录目标，不代表已全部实施：

## 1. 当时的研究结论（需重新核实）

### 1.1 不是只有 OpenAI 可以完成

本项目的图片调整不依赖某一家模型。国产模型已经具备参考图编辑、局部重绘、mask 引导、主体保持和多图参考能力，可以作为正式生产方案。

当时列出的候选组合（不是当前已验证的购买或生产建议）：

- **国产主力：Qwen-Image-2.1 或千问云端当前图像编辑模型。**
- **国产备选：SeedEdit 3.0 / Seedream 图像编辑系列。**
- **质量对照：OpenAI `gpt-image-2.5-sunburst`。**
- **确定性处理：本地图像脚本，不交给生成模型。**

### 1.2 当时拟定的供应策略

原计划采用“国产主力 + 国产备选 + OpenAI 小样对照”，而不是把生产流程绑定在单一服务上；当前项目没有执行此三模型对照实验。

正式批量生成前，使用同一张参考图、同一张 mask 和同一段提示词做一轮小样测试。根据实际输出选择本项目最终模型。厂商宣传和公开榜单只作为候选筛选依据，不能代替项目内测试。

### 1.3 严格像素一致性的可选方案（当前未实施）

任何生成模型都不能被假设为会严格保持 mask 外像素不变。

若新项目要求缺损区域以外逐像素不变，建议采用强制合成：

```text
最终残缺态 = 完整母版 × 非缺损区域 + 模型编辑结果 × 缺损区域
```

也就是：模型只负责生成缺损区域，mask 外从完整母版复制回来。当前项目采用提示词局部编辑与前端缺损区叠层，没有实施这套离线强制合成，不能把它写进实际交付流程。

## 2. 2026-09-21 的模型能力记录（非实时结论）

### 2.1 OpenAI GPT Image

#### 推荐型号

- 精确编辑优先：`gpt-image-2.5-sunburst`。
- 兼容或对照：`gpt-image-2`。

#### 适合任务

- 完整石像母版生成。
- 使用参考图和 mask 的局部破损。
- 建筑、底座、碎石的风格一致生成。
- `zhu2` 局部补画或扩图。
- 多轮对话式迭代。

#### 已知边界

当时的官方资料指出：mask 对生成模型具有引导作用，不能据此假设边界绝对精确。若新项目要求编辑区外逐像素一致，可增加 mask 外区域强制贴回；当前项目没有实施这一步，实际效果须单独验收。

#### 官方资料

- [OpenAI 图像生成工具：型号与编辑能力](https://developers.openai.com/api/docs/guides/tools-image-generation?site_locale=en)

### 2.2 Qwen-Image / 千问图像编辑

- 自部署或支持该版本的平台：`Qwen-Image-2.1`。
- 千问云端：使用账号所在区域实际提供的最新图像编辑型号，例如官方文档当前示例中的 `qwen-image-3.0-pro`，并记录完整型号和版本。

#### 适合任务

- 使用独立 mask 的主石像局部破损。
- 多参考图的画风统一。
- 独立主体生成与透明背景编辑。
- 主体 RGBA 提取的辅助测试。
- 正立面佛塔、石台和碎石组生成。

#### 官方能力摘要

Qwen-Image-2.1 官方说明包含：

- 文生图与图像编辑统一。
- 原生透明图生成和编辑。
- 最多 10 张参考图。
- 圆圈、涂抹和独立 mask 的局部编辑。
- 主体和产品的外观保持。

千问云端图像编辑文档还提供：

- 多参考图输入。

- 多结果输出。

- 自定义输出尺寸和负向提示词。

## 3. 任务与工具分工

| 任务 | 是否使用生成模型 | 首选 | 备选 | 最终确定性处理 |
|---|---:|---|---|---|
| `zhu2` 放大、平移、裁切 | 否 | 图像脚本/编辑软件 | 前端构图参数 | 保存明确裁切坐标 |
| `zhu2` 降对比、降饱和 | 否 | 图像脚本/编辑软件 | 色彩管理工具 | 固定调色参数 |
| `zhu2` 底部补画、扩图 | 是 | SeedEdit/Seedream | Qwen、GPT Image | 与原图羽化合成 |
| 完整主石像母版 | 是 | Qwen | GPT Image、Seedream | 选定后冻结母版 |
| 从母版生成残缺态 | 是 | Qwen mask 编辑 | SeedEdit、GPT Image | mask 外强制贴回 |
| 缺损 mask | 否或半自动 | 人工/脚本绘制 | 模型辅助分割 | 人工检查边界 |
| 正立面佛塔 | 是 | Qwen | GPT Image、Seedream | 透视和边缘检查 |
| 石台与碎石组 | 是 | Qwen | Seedream、GPT Image | 去投影和抠底 |
| 白纸背景抠图 | 否 | 自适应纸色脚本 | 人工检查 | 输出透明 PNG |
| 水彩边缘去黄边 | 否 | 图像脚本 | 人工修边 | 保留半透明羽化 |
| 重心、接地线和 JSON | 否 | 图像分析脚本 | 无 | 程序计算 |
| 屏幕空间纸纹 | 否 | Three.js Shader | 无 | 固定屏幕 UV |

### 3.1 不应交给生成模型的任务

以下任务要求确定性和可复现性，不使用生成模型：

- 批量纸色估计。
- alpha 斜坡计算。
- 连通域去噪。
- 中值滤波。
- 内容包围盒裁切。
- 水平重心和接地线计算。
- PNG/WebP 格式转换。
- JSON 元数据输出。
- mask 外像素强制贴回。
- `zhu2` 的常规裁切、位移和调色。

## 4. 主石像生产流程预案（当前未按此逐项执行）

### 4.1 生成完整母版

1. 确定统一画风提示词。
2. 每个候选模型生成 4–8 张完整石像。
3. 保持相同目标尺寸和宽高比。
4. 不在这一阶段生成残缺态。
5. 依据正立面程度、手势、衣纹、莲座、边缘清晰度和画风统一度筛选。
6. 选定唯一完整母版后，计算 SHA-256，并标记为冻结文件。

母版冻结后不得再次用模型重绘整尊石像。

### 4.2 制作缺损 mask

mask 建议至少分成两版：

- `damage-mask-hard.png`：用于强制合成，边界较明确。
- `damage-mask-soft.png`：用于网页补全动画，带羽化过渡。

mask 规则：

- 白色表示允许模型修改或允许完整态显现。
- 黑色表示严格保持母版。
- 模型输入 mask 可比最终缺损区域略宽，为生成断面留出上下文。
- 强制合成 mask 应比模型输入 mask 略窄，防止接缝。

### 4.3 局部生成残缺态

每个候选模型至少生成 4 张：

- 输入：完整母版。
- 输入：独立缺损 mask。
- 提示词：只在 mask 内制造石材缺口、断面和裂纹。
- 固定：画布尺寸、参考图、提示词版本。
- 尽可能固定 seed。

模型输出不能直接作为最终残缺态。

### 4.4 强制合成（可选严格模式，未实施）

设：

- `I`：完整母版。
- `E`：模型编辑结果。
- `M`：归一化缺损 mask，缺损区为 1，保留区为 0。

最终残缺态：

```text
B = I × (1 - M) + E × M
```

接缝区域可对 `M` 做少量羽化，但不能让羽化扩展到大面积未损坏身体。

### 4.5 拟议输出目录（未落地）


## 5. `zhu2` 图片调整流程

### 5.1 不需要模型的部分

1. 读取原图尺寸和色彩信息。
2. 生成桌面和移动端非破坏性裁切方案。
3. 桌面版将巨塔移到画面约 35%–40% 位置。
4. 裁掉或遮住底部约 12%–20%。
5. 降低对比度、饱和度和黑线密度。
6. 弱化原图纸纹。
7. 输出调色前后对比图。

以上步骤必须保存参数，不能只保存“调好了”的结果。

### 5.2 可能需要模型的部分

仅在以下情况下使用模型：

- 裁切后需要补齐画面边缘。
- 底部移除人物或街道后留下明显空洞。
- 移动端竖屏需要扩展天空或远山。
- 巨塔周围需要补充与原画一致的水彩背景。

优先顺序：

1. SeedEdit/Seedream。
2. Qwen 图像编辑。
3. GPT Image 对照。

模型补画后仍需与原图做局部羽化合成，不让模型重绘整张 `zhu2`。

### 5.3 水印与授权

- 优先从原生成平台获取有权使用的无水印导出。
- 如果平台提供关闭水印的合法参数，应在重新生成时关闭水印并保存调用记录。
- 对现有图片的水印处理必须确认素材归属和平台条款。
- 不以生成模型擦除水印作为默认流程。
- 若无法确认权限，采用裁切、重新生成或保留来源标记的方式处理。

## 6. 模型小样测试方案

### 6.1 测试集

至少包含：

1. 一张完整石像母版。
2. 一张头部缺损 mask。
3. 一张包含细线和淡色笔触的正立面建筑。
4. 一张 `zhu2` 局部补画区域。

### 6.2 统一测试条件

- 使用同一份源图。
- 使用同一份 mask。
- 使用语义一致的提示词。
- 输出尺寸尽可能一致。
- 每个模型生成至少 4 张。
- 记录 seed；不支持 seed 时注明“不支持/未暴露”。
- 不在测试途中随意修改提示词；提示词改版必须增加版本号。

### 6.3 评分维度

| 维度 | 权重建议 | 判断方法 |
|---|---:|---|
| 编辑区域质量 | 25% | 缺口是否像真实石材断面，有无 AI 糊块 |
| 非编辑区域保持 | 25% | 手势、衣纹、莲座、轮廓是否漂移 |
| 画风一致性 | 20% | 线条、水彩晕染、纸色是否与母版一致 |
| 指令遵循 | 15% | 是否只破坏指定区域、没有新增物体 |
| 边缘可合成性 | 10% | mask 边界是否自然、是否产生明显接缝 |
| 分辨率与细节 | 5% | 输出是否足够用于主景显示 |

### 6.4 可计算指标

自动指标只用于辅助，不代替人工审美判断：

- mask 外像素差异均值。
- mask 外 PSNR / SSIM。
- 主体轮廓 IoU。
- 关键点或轮廓位移像素。
- 色彩平均差异。
- 输出尺寸、文件体积和耗时。

强制合成后，mask 外像素应与母版完全一致；如果不一致，说明合成流程有问题。

### 6.5 淘汰条件

出现以下任一问题即淘汰该输出：

- 未损坏手势发生改变。
- 衣纹或莲座明显重画。
- 缺口呈马赛克、模糊块或涂抹感。
- 新增人物、光环、碎片、背景或地面。
- 输出透视发生变化。
- 分辨率不足或边缘不可抠取。
- 与现有素材画风明显不一致。

## 7. 文件与版本命名

### 7.1 文件命名格式

```text
<asset>-<state>-<model>-<promptVersion>-<seed>-<run>.<ext>
```

示例：

```text
statue-broken-qwen-image-2-1-p03-248113-r04.png
pagoda-front-seedream-p02-73102-r02.png
zhu2-outpaint-gpt-image-2-5-sunburst-p01-no-seed-r01.png
```

### 7.2 禁止覆盖

- 原始生成结果不可覆盖。
- 提示词改动必须新增版本文件。
- mask 改动必须新增版本号。
- 调色输出不得覆盖 `zhu2.png`。
- 通过筛选的最终文件通过复制或构建流程进入 `processed`，不从原始目录移动。
